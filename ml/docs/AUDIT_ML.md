## 2. Гипотезы, что ещё упустили (по слоям, с приоритетами)

### Слой B — поиск (после стабилизации интеграции)

- [B1] **QUERY_PREFIX** «Represent this sentence for searching relevant passages: » —
  инструкция для e5-семейства; **bge-m3 префиксов не требует** и может снижать качество.
  Тест: сабмит-вариант без префикса после стабилизации (± recall).
- [B2] **Чанкинг v2** — «ювелирная разбивка решает» (организатор): структурные границы
  (номера пунктов/статей), наследование заголовка в чанк, склейка перекрытий.
  Главный рычаг качества на 2–3 день.
- [B3] **Даты создания/изменения** документов в вопросах: companion-редакции закрывают
  «ред. 2023/2025»; даты писем (№, от dd.mm.yyyy) — в чанк-заголовок для поиска.
- [B4] Реранк: формат запроса совпадает с примером оргов; если платформа задаёт
  `RERANKER_MODEL` — включится автоматически (косинусные скоры для порога не трогаем).
- [B5] `extractive_answer(top[:2])` → расширить до `top[:3]`, предложения длиннее.

### Слой C — ответы и судья

- [C1] Судья = сравнение с baseline (0/0.25/0.5/0.75/1.0 за вопрос; выдумка = 0).
  Стратегия ответа: вывод → нормы с пунктами → цитаты → «Источник:». Полнота против
  golden важнее краткости (регламент: «до 150 слов рекомендуется, подробнее допустимо»).
- [C2] Формат диалогов: наш парсер ждёт «Пользователь:/Ассистент:» построчно.
  Уточнить реальный формат у оргов/по демо (могут быть «User:/Assistant:» или одна строка).
- [C3] Промпт-правила 9–10 (иерархия, «Источник:») ещё ни разу не оценивались судьёй
  (генерация была мертва) — считать неактивными до первого живого сабмита.
