## 2. Гипотезы, что ещё упустили (по слоям, с приоритетами)

  инструкция для e5-семейства; **bge-m3 префиксов не требует** и может снижать качество.

  Главный рычаг качества на 2–3 день.

  «ред. 2023/2025»; даты писем (№, от dd.mm.yyyy) — в чанк-заголовок для поиска.
- [B4] Реранк: формат запроса совпадает с примером оргов; если платформа задаёт
  `RERANKER_MODEL` — включится автоматически (косинусные скоры для порога не трогаем).
- [B5] `extractive_answer(top[:2])` → расширить до `top[:3]`, предложения длиннее.

### Слой C — ответы и судья

  golden важнее краткости (регламент: «до 150 слов рекомендуется, подробнее допустимо»).
