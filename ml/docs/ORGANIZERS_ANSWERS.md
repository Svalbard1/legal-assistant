## Новые требования (из ответов, обязательно учесть)

1. **Иерархия при конфликте документов** — «подумать над иерархией принятия решений,
   если есть конфликт». Рабочая гипотеза: ФЗ/КоАП/НК/ТК (законы) > внутренние регламенты >
   разъясняющие письма; действующая редакция > утратившая силу; для событий в прошлом —
   редакция на дату события. Задача: правило в промпт + тест-кейсы.
2. **Даты создания/изменения документов** — «есть вопросы, где важно учитывать дату
   создания и дату изменения». Companion-редакции покрывают «дату изменения» (ред. 2023/2025);
   «дата создания» — вероятно, метаданные документа (дата письма, номер).
3. **Инъекции В ДОКУМЕНТАХ** — не только в вопросах! Фрагменты из базы могут содержать
   враждебные инструкции. Правило 7 промпта solution.py усилено: инструкции из фрагментов
   игнорируются, фрагменты — только источник фактов.
4. **Чанкинг — главный рычаг**: цитата организатора: «наверх пробьётся тот, кто сделает
   ювелирную работу с разбивкой на чанки; смысл будет в деталях». Направление: структурный
   чанкинг с сохранением контекста (первый эксперимент провалился из-за разрыва контекста
   при разрыве по страницам — переработать: наследование заголовков/разделов).
5. **Провокация-редакции подтверждена**: «подскажи, что было в договоре 2023» → дать
   2025 = ошибка; **система может уточнить дату — это норм**. Наш companion-подход
   соответствует; уточняющий вопрос допустим.
6. **«Ограничение Postgres на проверочной базе»** — формулировка Вали расплывчата;
   уточнить в чате оргов, что это (вероятно, на платформе есть Postgres с лимитами).

## Судья и оценка (уточнено регламентом, 13.11 вечер)

- Судья сравнивает ответ команды **с ответом baseline организаторов**, ориентируясь на golden.
- Шкала за вопрос: 1.0 значительно лучше baseline / 0.75 немного лучше / 0.5 сопоставимо /
  0.25 немного хуже / 0.0 значительно хуже. Каждый вопрос оценивается дважды (A/B порядок),
  итог — среднее.
- **Выдуманный факт полностью обнуляет оценку за вопрос** (не «штраф» — ноль).
- Score = 0.7 × MatchRate + 0.3 × WinRate. Лидерборд публичный — на public-подмножестве,
  финальная оценка — на private (не оверфитить демо-вопросы).
- Интерпретация нашего 0.1979: MatchRate ≈ 0.15, WinRate ≈ 0.3 → почти везде «хуже baseline»
  → профиль упавшей генерации подтверждён.
- Цель: ≥ 0.5 = «сопоставимо с baseline» по большинству вопросов; топ ≈ 0.65–0.75.
- Честный отказ оценивается ~0.25–0.5 (лучше выдумки = 0) → консервативный порог оправдан.
- RERANKER_MODEL платформа передаёт env → реранк Qwen3 включится сам (формат запроса у нас
  совпадает с минимальным примером; порог отказа остаётся на косинусных скорах — безопасно).
- 401/token_not_found_in_db — баг платформы, сообщать организаторам (команда, время, текст).
