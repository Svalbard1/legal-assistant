# Автоматический сабмит (solution.py)

Точка входа для платформы Hack&Change: читает `DATA_DIR/questions.csv` и
`DATA_DIR/knowledge-base.zip`, ищет по базе знаний, генерирует ответы через
OpenAI-совместимый прокси платформы, создаёт `submission.csv`.

## Ключевые требования регламента (шпаргалка)

| Параметр | Значение |
|---|---|
| Состав ZIP | корень архива без папок: `solution.py`, `requirements.txt`, корневые `.py` |
| Лимиты | 128 МБ, 8 CPU, 16 ГБ RAM, **20 минут**, 5 сабмитов/день |
| Переменные | `LLM_BASE_URL`/`OPENAI_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`/`GEN_MODEL`, `DATA_DIR` (default `data`), `TEMPERATURE`, `MAX_TOKENS`, `MAX_WORKERS`, `TOP_K`, `EMB_MODEL` |
| Запросы LLM | `{LLM_BASE_URL}/chat/completions`, `Authorization: Bearer {LLM_API_KEY}` |
| Эмбеддинги | bge-m3 через тот же прокси (`/embeddings`); реранкер Qwen3 Reranker 8B (необязателен) |
| Ответы | `id,answer`, непустые, ≤10 000 символов, CSV-экранирование |
| Судья | MatchRate 70% + WinRate 30%; **выдуманный факт = 0 за вопрос**; нельзя pip install из кода |
| Секреты | ключи только через env платформы, не хранить в коде/логах |

## Логика решения (деградация без потери сабмита)

1. **Эмбеддинги через прокси** (bge-m3) → косинусный топ-K; score < порога → обоснованный отказ.
2. **Прокси недоступен → BM25** на чистом Python (лексический поиск без зависимостей).
3. **LLM недоступна → выжимка найденных фрагментов** — `submission.csv` обязан существовать
   и быть полным, поэтому аварийных путей с пустыми ответами нет.

Промпт зашивает правила кейса: цитирование документа и пункта, отказ при нехватке
данных, учёт редакции на дату, непрофильные вопросы, защита от смены роли, история диалога.

## Локальная проверка

```bash
# собえた фейковые DATA_DIR + mock-прокси: три сценария описаны в git-истории команды;
python3 -m py_compile solution.py
python3 build_zip.py        # собирает ZIP в ml/
```

Перед сабмитом: положить в ZIP актуальный корневой набор и убедиться, что
`requirements.txt` содержит только разрешённые платформой библиотеки.
