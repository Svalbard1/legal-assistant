# Презентация проекта

- [`presentation.pdf`](presentation.pdf) — готовая версия для отправки экспертам (10 слайдов).
- [`presentation.html`](presentation.html) — редактируемый HTML-макет (архивная версия; перед отправкой пользоваться PDF и источником сборки ниже).
- [`build_presentation.py`](build_presentation.py) — скрипт пересборки PDF из векторной разметки; требуется Python и `reportlab`.
- [`assets/ui-chat.png`](assets/ui-chat.png) и [`assets/ui-documents.png`](assets/ui-documents.png) — скриншоты локального интерфейса, встроенные в слайд 4 PDF.

Содержимое намеренно не включает закрытые документы и базу кейса. Пример договора обозначен как синтетический. Скриншот страницы документов показывает тестовое состояние локальной базы: один файл проиндексирован, у второго ошибка индексации; это иллюстрация сценария ошибки, а не утверждение о чистом первом запуске. Метрики подписаны как локальные retrieval-eval; это не оценка генерации, юридической точности или официальный платформенный балл. Публичный demo URL не заявлен: на первом слайде дан порядок локальной проверки и ссылка на GitHub.

Скрипт PDF — источник актуального содержимого. HTML-макет пока не синхронизирован с ним и содержит устаревшие формулировки (в частности, про загрузку через Backend и часть описания проверки); не отправляйте HTML как презентацию.
